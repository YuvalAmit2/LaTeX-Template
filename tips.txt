The file main.tex includes almost all my commands for writing math. Normally, this is something one would put in a preamble file, but I write primarily with Overleaf's live math display in the text editor, which requires me to define those commands in the same document I write in. If you're using this template in almost any other way, I'd recommend moving these to preamble.tex or elsewhere


--Putting TikZ in TColorBox--
Select "ampersand replacement" in quiver
Mathcha should work fine


--Writing one line on top of another--
\substack{\\}

--Using Figbox--
To put a figure in another box, use \figbox{} without the outer "figure creater". For example, remove \begin{graphics} or \begin{table}

--Formatting a Sum Tighter--
\mathclap{}

--Bold Math Text--
\bm
