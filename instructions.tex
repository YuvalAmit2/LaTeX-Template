Welcome! Here's a quick tutorial on how to use my template.

\section{Modes}

This template has three modes:
\begin{itemize}
    \item Notes mode: used for course notes and problem sets. Prioritizes readability (and color!)
    \item Paper mode: used for papers (duh)
    \item Presentation mode: used for beamer presentations
\end{itemize}
If you are using this template on your own, you can switch between these three modes by commenting and uncommenting the corresponding code at the top of main.tex.

If you're collaborating with me on something, chances are we're already in the correct mode, so no need to mess with it.

\section{Commands}

Like most templates, this one has a large list of custom commands. Note that the file main.tex includes almost all my commands for writing math. Normally, this is something one would put in a preamble file, but I write primarily with Overleaf's live math display in the text editor, which requires me to define those commands in the same document I write in. If you're using this template in almost any other way, I'd recommend moving these to preamble.tex or elsewhere.

\section{Theorem-like Environments}
\subsection{Notes Mode}
The biggest difference between notes mode and paper mode is the format of ``theorem-like'' environments, which is what I call environments like theorems, definitions, examples, etc.

\begin{lstlisting}[language={[LaTeX]TeX}]
\begin{<type>}[custom_name][extra_optional_args]
   text
\end{<type>}

% <type> can be: thm, lem, ex, defn, prop, rmk, cor, note, que, exer, conj
\end{lstlisting}

The first optional argument is used to give the environment a custom name. The second optional argument is for making any changes/addition to the underlying tcolorbox environment (most commonly, adding a label).

\begin{defn}
    This is a colorful \textbf{box}!
\end{defn}

\begin{ex}
    These boxes are colorful
\end{ex}

\begin{thm}[Fermat's Last Theorem][label=thm:fermat]
    The equation $a^n+b^n=c^n$ has no non-trivial integer solutions for $n \geq 3$.
\end{thm}

You can reference thm-likes with \verb|\cref{label}|. For example, \cref{thm:fermat}.

There are a few other special cases for environments. 

The \verb|note| environment says ``Note'' by default, and has no number. The first optional argument gives it a different name, so it can be used for general purposes. The second optional argument is the same as the rest of the boxes.

\begin{note}[Notation]
    We write $\N = \{0,1,\dots\}$.
\end{note}

The \verb|exercise| environment works very differently. It's visually distinct, takes no optional arguments, and is not numbered by section.

\begin{exercise}
    Prove that every finite integral domain is a field.
\end{exercise}

\subsection{Paper Mode}

Due the LaTeX limitations, I cannot switch the settings of this document in the middle, so unfortunately I can't explicitly show the thm-like environments for Notes mode, Paper mode, and Presentation mode at the same time.

Here's how to make a thm-like in Paper mode:
\begin{lstlisting}[language={[LaTeX]TeX}]
\begin{<type>}[custom_name] \label{...}
   text
\end{<type>}

% <type> can be: thm, prop, rmk, cor, defn, lem, ex, que, exer, conj
% custom_name and \label{} are both optional
\end{lstlisting}

These environments are automatically numbered within section. To make a thm-like without a number, place a \verb|*| next to \verb|<type>|:

\begin{lstlisting}[language={[LaTeX]TeX}]
\begin{<type>*}[custom_name]
   text
\end{<type>*}

% note that a thm-like without a number can't be referenced with \cref
\end{lstlisting}

See \verb|paper_settings/thms_setup.tex| for the source code.

\subsection{Presentation Mode}

When using Beamer, I've found it's best to stick with the native block environments rather than creating custom thm-likes. The block environments look more natural, and don't need fancy features like numbering and referencing. To make a frame (a slide) and a block (a ``thm-like''):

\begin{lstlisting}[language={[LaTeX]TeX}]
\begin{frame}{Frame Title}
    \begin{block}{Custom Name}
        Text
    \end{block}
\end{frame}
\end{lstlisting}
