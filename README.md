## Thanks/Disclaimers

As all good LaTeX templates do, this started as something I "borrowed" from others. The very first versions of my template (back when it was just a few commands and theorem enviornments) came from "borrowing" the templates of Foivos Chnaras and Niranjan Ramachandran.

Big thanks to Jason Chen (who doesn't know who I am), whose publicly available LaTeX template particularly inspired the structure of thms_boxs.tex and thms_setup.tex. Their code can be found [on github](https://github.com/chezbgone/chez-sty.git).

I'm proud to say that a large majority of the advanced functionality of the template came from me reading various documentation for different packages, [TeX Stack Exchange](https://tex.stackexchange.com/) answers, and Overleaf's [extensive list of tutorials](https://www.overleaf.com/learn). Huge shoutout to those who took the time to write readable documentation, to those who wrote good answers on Stack Exchange questions 8 years ago, and to the Overleaf devs for creating the best LaTeX interface (in my (correct) opinion) and starter guides.

That said, there were a few things I wanted to add to the template, but couldn't figure out how to do. For these, I occasionally used assistance from AI. All AI-generated code has been properly labeled as such, to the best of my ability.

If you're looking to ask me questions about the template: I probably understand most of the code that's not labeled as AI-generated. I probably don't understand most of the code that is labeled as AI-generated (e.g. I have no idea what \makeatletter does).
